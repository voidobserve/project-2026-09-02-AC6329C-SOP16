| 显示屏显示内容 | 说明                                                   |
| -------------- | ------------------------------------------------------ |
| PASS           | 是对应的按键                                           |
| KEY            | 按键的键值                                             |
| RSSI           | 信号强度                                               |
| TYPE           | 按键类型（例如：24-24键2.4G遥控器，28-28键2.4G遥控器） |

- 指示灯，如果是对应的按键，点亮。不是对应的按键，熄灭

- OLED是0.96寸的，IIC接口
